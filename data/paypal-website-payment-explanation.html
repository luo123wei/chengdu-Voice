一、业务与网站简介

本公司运营独立站 Voice Culture（https://www.voiceculture.world），主营成都主题文化创意商品的设计与跨境零售，包括：

  • 实物商品：火漆印章、皮质钥匙扣、熊猫主题文创摆件等小批量手工艺品，从中国通过国际物流发往全球，提供物流追踪号；
  • 数字商品：成都城市声音数字音频专辑（Chengdu Sound Library，30 秒/段的川剧、方言、茶馆等环境录音），顾客付款后可立即在线下载，无需物流。

网站由本公司自主运营，基于 Next.js 技术构建，部署于 Render 云平台，使用 Supabase 数据库管理商品与订单。

二、PayPal 集成方式

本公司通过 PayPal 官方提供的 PayPal 全球收单（标准版）/ PayPal Checkout 接入收款，使用 PayPal 官方 REST API 与 JavaScript SDK（均为 PayPal 官方文档规定的标准集成方式）：

  • 下单接口：POST https://api-m.paypal.com/v2/checkout/orders（订单金额由本公司服务器根据购物车商品价格计算，买家无法篡改）；
  • 扣款接口：POST /v2/checkout/orders/{order_id}/capture（买家在 PayPal 页面授权后，由本公司服务器确认扣款）；
  • 前端使用 PayPal JavaScript SDK 渲染官方支付按钮，买家可使用 PayPal 余额、绑定的信用卡/借记卡（支持访客无 PayPal 账户付款）完成支付；
  • API 凭证（Client ID / Secret）通过 PayPal Developer 平台（developer.paypal.com）Live 生产环境创建，密钥仅保存在服务器环境变量中，不对外公开。

三、顾客支付与发货流程

  1. 顾客在网站浏览商品、加入购物车，填写收货地址（数字商品无需地址）与邮箱；
  2. 结账页由服务器重新核算商品金额、运费与折扣（如新人九折码 WELCOME10），向 PayPal 创建订单；
  3. 顾客点击 PayPal 按钮，跳转/弹窗至 PayPal 官方页面登录并完成付款授权；
  4. 付款经 PayPal 确认成功（状态 COMPLETED）后，网站才生成正式订单；若付款失败或取消，订单自动作废，不发货；
  5. 实物商品：本公司在 1–3 个工作日内发货，通过国际邮政/快递配送并向顾客提供追踪号；数字商品：付款成功页面立即展示全部音频文件的下载链接，顾客可随时下载；
  6. 订单确认信息通过网站订单页面及电子邮件发送给顾客。

四、退款与客服政策

  • 实物商品支持收货后 14 天内无理由退换（商品完好前提下），质量问题由本公司承担退货运费；退款通过 PayPal 原路径退回（Refund API）；
  • 数字音频商品因可即时下载，下载前可全额退款，下载后不支持退款（该条款在商品页及结账前明确公示）；
  • 顾客可通过邮箱 hello@voiceculture.world 联系客服，本公司承诺 48 小时内回复，并配合 PayPal 调解中心（Resolution Center）处理任何争议。

五、资金结算

顾客支付的美元款项进入本公司 PayPal 企业账户后，本公司通过 PayPal 跨境收款产品将资金结算为人民币，提现至本公司境内对公银行账户，全程在 PayPal 体系内完成，合规结汇，依法纳税。
